My co-op was on UKG's internal generative-AI enablement team. After onboarding (Jira, PGP
keys, article reviews) I inherited a Python script that traversed a directory and
converted files to LLM-friendly text, and built a repository assistant on top of it. The program downloads
a requested GitHub repo with credentials, walks it with guardrails to avoid noise and
static files, interprets images and video, delegates PDFs and tabular files, and writes
metadata to every output. I ended the co-op on a good note with a working VSCode
extension to pass onto the next developer who takes on the project.
