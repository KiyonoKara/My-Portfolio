I wrote an **HTTP/HTTPS client library** that was built on Java's native
networking stack and published to GitHub's Maven registry. It was inspired by com-lihaoyi's
**requests-scala**, itself a port of Python's **requests**. Scala gave me a **type-safe and semi-object-oriented** approach
to build this. The library simplifies API calls and general HTTP work.
This project got me into Scala, and I'm quite fond of it.
